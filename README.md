# Workshop Viagem Possível ao Vivo

Página de vendas de Márcio e Grazi para o Workshop Viagem Possível ao Vivo.

## Tecnologias

- Next.js
- React
- TypeScript
- CSS

## Rotas

- `/a1`
- `/a2`
- `/a3`
- `/obrigado`

As três páginas de venda compartilham toda a estrutura e o conteúdo. Somente a mensagem principal no início da página muda entre as versões.

## Execução local

```bash
pnpm install
pnpm dev
```

Abra `http://localhost:3000/a1` no navegador.

## Build de produção

```bash
pnpm build
pnpm start
```

## Conteúdo operacional

As informações confirmadas, os valores derivados para os lotes e os dados necessários antes da abertura das vendas estão em `docs/informacoes-operacionais.md`.
